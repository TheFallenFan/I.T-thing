From Toby: My code is a soil moisture sensor. It uses two DHT11 sensors (pins 16 and 17) and averages their readings. If the average is 49% or lower, the LED on pin 15 turns on (acting as a water valve) and the buzzer sounds for 30 seconds while it “waters.” If it’s above 49%, it prints “Enough moisture, not watering.” It prints both readings and the average every second, so you can check what it’s doing. To change when it waters, edit the 49 in the code.
