From Toby: My code is a soil moisture sensor. It uses two DHT11 sensors (pins 16 and 17) and averages their readings. If the average is 49% or lower, the LED on pin 15 turns on (acting as a water valve) and the buzzer sounds for 30 seconds while it “waters.” If it’s above 49%, it prints “Enough moisture, not watering.” It prints both readings and the average every second, so you can check what it’s doing. To change when it waters, edit the 49 in the code.
From James: My code is a Smart Traffic Light system (The code is located in file "Jame'sTrafficSequence.py". Using sensers to detect an object/movement. It's designated light swap from Green - Yellow - Red. This is overridden when motion is detected. If the light is on green and motion is detected it will extend it's time on green to keep the 'car' moving allowing it to make it the full way through. If on yellow it will swap to green with an extended time cap instantly. When on red it will first swap to yellow then it will swap to green with a extended time.
